这是一款名为 **Chrome Paimen** 的 2D 横版跑酷躲避游戏，使用 C++ 与 EasyX 图形库独立开发。
玩家将控制主角“**peimen**”在不断向前滚动的场景中奔跑，通过按空格键跳跃来躲避迎面而来的野猪障碍。
游戏不仅具备天空与地面速度不同的视差滚动效果，还内置了动态难度系统——随着得分增加，敌人的移动和场景滚动速度会逐渐加快；
每成功躲避一次即可得分，系统会实时通过 C++ 文件流将最高纪录持久化保存在本地的 `MaxScore.txt` 文件中，
游戏结束后按空格即可无缝重开。在技术实现上，该游戏包含了细腻的帧动画驱动、跳跃与落地粒子特效，
以及通过 Windows MCI 接口播放的背景音乐，是开发者作为一名高中生在学习游戏开发过程中，
综合运用面向对象编程、游戏主循环设计、时间步长（Delta Time）管理以及矩形碰撞检测等核心知识完成的学习项目。
